# 07 — AEO / GEO CONTENT STANDARD
**Vibe Clean Pro | الرياض | سبتمبر 2026**
**Answer Engine Optimization + Generative Engine Optimization**

---

## ما هو AEO/GEO وما علاقته بهذا الموقع؟

**AEO (Answer Engine Optimization):** كتابة محتوى يُجيب مباشرةً على أسئلة المستخدمين — هدفه الظهور في Featured Snippets، People Also Ask، ومحادثات ChatGPT/Gemini/Perplexity.

**GEO (Generative Engine Optimization):** تنظيم المحتوى ليُستشهد به في الإجابات التوليدية (AI Overviews في Google، إجابات Claude/ChatGPT عن شركات تنظيف الرياض).

---

## معيار الإجابة المباشرة (Direct Answer Standard)

### قاعدة BLUF — Bottom Line Up Front

```
كل صفحة خدمة يجب أن تُجيب على السؤال الرئيسي خلال 40-60 كلمة من بداية المحتوى.
لا مقدمات، لا "نرحب بكم في..."، لا تاريخ الشركة أولًا.

مثال صواب (facade-cleaning):
"تنظيف واجهات المباني في الرياض يشمل: إزالة الأتربة والبقع من الواجهات
الزجاجية والحجرية والكلادينج باستخدام معدات مخصصة للارتفاع (حبال/رافعة/سقالة)."

مثال خطأ:
"شركة Vibe Clean Pro هي رائدة في مجال التنظيف بالمملكة..."
```

## معيار هيكل الصفحة AEO

### التسلسل الإلزامي لكل صفحة خدمة

```
H1: الكلمة المفتاحية الرئيسية + الموقع
    مثال: «تنظيف واجهات المباني في الرياض»

Direct Answer Paragraph (60 كلمة): ما الخدمة؟ من يحتاجها؟ كيف تُنفَّذ؟

H2: «ماذا يشمل [اسم الخدمة]؟»
    → Bulleted List (قابل لـ Featured Snippet)

H2: «كيف تُنفَّذ [الخدمة]؟»
    → Numbered Steps (قابل لـ How-to rich result)

H2: «متى تحتاج [الخدمة]؟»
    → Decision Guide (أسئلة + إجابات قصيرة)

H2: «الأسئلة الشائعة» (FAQ)
    → كل سؤال → إجابة 40-80 كلمة (قابل للـ FAQPage Schema)
```

## معيار People Also Ask (PAA)

### الأسئلة الإلزامية لكل خدمة رئيسية

كل صفحة خدمة يجب أن تُجيب على هذه الأنواع:

| نوع السؤال | مثال | تنسيق الإجابة |
|---|---|---|
| «كم يكلف...؟» | كم يكلف تنظيف الواجهة؟ | نطاق + عوامل + CTA للتقييم |
| «كم يستغرق...؟» | كم يستغرق تنظيف فيلا؟ | مدة + متغيرات المدة |
| «ماذا يشمل...؟» | ماذا يشمل تنظيف المجلس؟ | Bulleted List |
| «هل آمن...؟» | هل تنظيف الكنب آمن للجلد؟ | مادة + إجراء + ضمان |
| «ما الفرق...؟» | الفرق بين التنظيف العادي والعميق | جدول مقارنة |
| «متى يجب...؟» | متى يجب تنظيف الخزان؟ | توصية + علامات |

## معيار AEO للأحياء

### الأسئلة المتوقعة في PAA لصفحات الأحياء

```
«هل تخدمون حي [اسم الحي]؟»
→ إجابة مباشرة: «نعم، نخدم [اسم الحي] وما حوله...»

«ما خدمات التنظيف المتاحة في [الحي]؟»
→ قائمة الخدمات مع روابط

«كيف أحجز خدمة تنظيف في [الحي]؟»
→ CTA + رقم واتساب
```

## معيار GEO — الاستشهاد في الإجابات التوليدية

### لكي تستشهد بنا Claude/Gemini/Perplexity يجب أن:

**1. الصفحة تُجيب على سؤال واضح بوضوح**
```
لا يكفي أن تُذكر الخدمة — يجب أن يكون المحتوى إجابةً كاملة
لسؤال المستخدم، بحيث يمكن اقتباسها مباشرةً.
```

**2. الصفحة تحتوي على فاكتات قابلة للاقتباس**
```
صواب: «تنظيف الواجهة بالحبال يناسب المباني التي يتجاوز ارتفاعها 4 طوابق.»
خطأ: «لدينا خبرة واسعة في تنظيف الواجهات المرتفعة.»
```

**3. المحتوى يستخدم entities واضحة (Named Entity Recognition)**
```
يجب ذكر:
- اسم الشركة: Vibe Clean Pro / فايب كلين برو
- الموقع: الرياض + أسماء الأحياء المحددة
- الخدمات: أسماء صريحة
- الأشخاص: المؤسس (إذا مناسب)
- التقنيات: نوع المعدات (رافعة، حبال، بخار، إلخ)
```

**4. AuthorEntity / BusinessEntity واضح**
```
/about: صفحة واضحة عن المؤسس بمعلومات حقيقية (موجود ✅)
Business Profile: مكتمل (موجود ✅)
Schema: LocalBusiness + Person (يحتاج تدقيق — انظر 08)
```

## معيار AEO للـ FAQ

### شروط الـ FAQ المثالي لـ AEO

```
✅ السؤال: كما يكتبه المستخدم بالفعل (لا الصياغة الرسمية)
   صواب:  «هل تستطيعون تنظيف الواجهة بدون قطع الكهرباء؟»
   خطأ:   «ما هي إجراءات السلامة الكهربائية لديكم؟»

✅ الإجابة: 40-100 كلمة — كافية ولا أكثر
   - أول جملة: الإجابة المباشرة (نعم/لا/يعتمد)
   - الجملتان التاليتان: التوضيح والشرط
   - الجملة الأخيرة: ما الخطوة التالية أو CTA خفيف

✅ لا أسئلة تسويقية — لا «لماذا تختاروننا؟»
✅ لا أسئلة يُجيب عليها محتوى الصفحة بالفعل (تكرار)
✅ كل خدمة: 6-10 أسئلة (لا أقل من 4، لا أكثر من 12)
```

---

## معيار AEO للـ Steps / How-To

### شروط الـ Steps المثالي للـ How-To Rich Result

```
✅ كل خطوة: جملة واحدة + تفاصيل قصيرة
✅ رقم الخطوات: 4-8 خطوات (لا أقل من 3، لا أكثر من 10)
✅ كل خطوة لها عنوان صريح (H3)
✅ لا خطوات تسويقية («تواصل معنا للحصول على أفضل خدمة»)
✅ الخطوات تصف الـ PROCESS الفعلي لتنفيذ الخدمة
```

**مثال صواب (facade-cleaning steps):**
```
الخطوة 1: تقييم الواجهة — تحديد نوع المادة والارتفاع وطريقة الوصول
الخطوة 2: اختيار المعدات — رافعة للمباني العالية، حبال للأسطح الشاقة
الخطوة 3: اختبار قسم صغير — تأكد من أن المادة لا تتأثر بالمنظفات
الخطوة 4: التنظيف من الأعلى للأسفل — لمنع تلويث المناطق المنظفة
الخطوة 5: الشطف بالماء النظيف — إزالة بقايا المنظفات
الخطوة 6: المعاينة مع المالك — تسليم موثق مع تقرير حال الواجهة
```

## قواعد AEO/GEO — ما لا يُفعل

```
❌ كتابة محتوى مُبهم لا يُجيب على سؤال محدد
❌ استخدام صياغات تسويقية مكان الإجابة الفعلية
❌ إجابات FAQ تتجاوز 150 كلمة
❌ FAQ بأسئلة لا يبحث عنها الناس بالفعل
❌ Steps تصف التسويق لا العملية
❌ ادعاء خبرة «30 عامًا» أو إحصاءات مختلقة
❌ محتوى عام ينطبق على أي شركة تنظيف في العالم
❌ استخدام «نحن الأفضل» بدون دليل حقيقي
```
