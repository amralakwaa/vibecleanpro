## قاعدة نشر صفحات الأحياء (AREA PAGE QUALITY GATE)

```
GATE CHECK — قبل نشر أي صفحة حي:

1. ✅ SEO Metadata كاملة (title + description)
2. ✅ محتوى نصي > 150 كلمة مميزة
3. ✅ لا تشابه > 70% مع صفحة حي أخرى
4. 🎯 DESIRED: مشروع حقيقي مرتبط بالحي
5. 🎯 DESIRED: FAQ محلي (أسئلة خاصة بالحي)
6. ✅ Internal links: خدمات متاحة في المنطقة
7. ✅ Tier: B أو A فقط (C = BLOCKED)

إذا لم يتحقق 1-3 → NOINDEX أو دمج أو حذف
إذا تحقق 1-3 بدون 4-5 → PUBLISHED ولكن بدون AdWords + موسوم للتطوير
إذا تحقق كل شيء → FULL PUBLISH + Internal links
```

## الاستراتيجية الصحيحة للأحياء

### ما يجب أن تحتويه صفحة الحي القوية

```
1. HERO — صورة من مشروع حقيقي في الحي (إذا توفرت)
2. DIRECT ANSWER — «خدمات التنظيف في [اسم الحي]»
3. خصائص الحي العقارية ذات الصلة:
   - شمالي راقٍ: فلل كبيرة + واجهات + مجالس
   - تجاري: مكاتب + محلات + واجهات
   - أحياء جديدة: ما بعد البناء/التشطيب
   - أحياء شعبية: كنب + منازل + مكيفات
4. الخدمات الأكثر طلبًا في هذا الحي (مع مراعاة طبيعته)
5. مشاريع منفذة (بعد تأكيد owner_confirmed_at)
6. FAQ محلي (أسئلة لا تنطبق على حي آخر)
7. أحياء مجاورة (internal links)
8. CTA محلي
```
