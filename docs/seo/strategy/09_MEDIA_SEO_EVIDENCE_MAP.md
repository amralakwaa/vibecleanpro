## معيار SEO لكل صورة

### Alt Text — الإلزامي

```
الصيغة المثلى: [وصف العمل] + [نوع الخدمة] + [الموقع إن أمكن]

مثال صواب:
«عمال يُنظفون واجهة برج زجاجي بالرافعة في حي العليا بالرياض»

«سطح رخامي مصقول لامع بعد جلي الرخام في فيلا بحي الياسمين»

«كنب جلد بعد تنظيف احترافي بالبخار في منزل بالرياض»

مثال خطأ:
«صورة 1» / «img-12345» / «تنظيف»
```

### File Naming (للملفات الجديدة في المستقبل)

```
الصيغة المثلى (للملفات الجديدة فقط):
[خدمة]-[موقع]-[رقم].jpg

مثال: facade-cleaning-al-malqa-01.jpg

لا تُغيَّر أسماء الملفات في المكتبة الحالية.
```
