# 12 — MASTER PUBLISHING GATE
**Vibe Clean Pro | الرياض | سبتمبر 2026**
**الحكم النهائي قبل نشر أي صفحة**

> هذا الملف يُلخِّص قواعد النشر المستخرجة من الكود (PublishingGate.php)
> وإضافات استراتيجية لهذا المشروع.

---

## بوابة الخدمات (Services Gate)

```
✅ تمر للنشر:
  1. SEO Metadata: title + description (ليست null)
  2. H1 وصفي (ليس اسم الشركة)
  3. Content blocks: ≥ 1 rich_text + 1 cta
  4. لا cannibalization مع صفحة خدمة أخرى
  5. صورة cover: من D:\VibeCleanPro_Media.zip فقط

⚠️ تحذيرات (لا تمنع النشر، لكن تُدوَّن):
  - لا FAQ blocks (مقبول لكن أضعف)
  - لا steps blocks (مقبول لكن أضعف)
  - لا صور مشاريع مرتبطة (تُخفَّض أولوية الـ Sitemap)

❌ تُحجب من النشر:
  - Service بدون title أو description
  - Service بمحتوى < 150 كلمة (thin content)
  - Service بصور من مصادر غير مرخصة
  - Service جديدة بدون موافقة المالك على المحتوى
```

---

## بوابة الأحياء (Areas Gate)

```
✅ تمر للنشر:
  1. SEO Metadata: title + description
  2. محتوى نصي: > 150 كلمة مميزة
  3. تشابه مع أحياء أخرى: < 70%
  4. Tier: B أو A فقط

⚠️ تحذيرات لا تمنع النشر:
  - area_id = NULL لكل المشاريع (طبيعي حتى التأكيد)
  - بدون FAQ محلي (موصى به لكن غير إلزامي)
  - بدون صورة cover (يُعيق E-E-A-T لكن لا يمنع)

❌ تُحجب:
  - Tier C — محجوبة بالكامل
  - محتوى متطابق مع حي آخر > 70% تشابه
  - حي بدون metadata
```

---

## بوابة المشاريع (Projects Gate)

```
✅ تمر للنشر (تطبّق الآن):
  1. owner_confirmed_at NOT NULL
  2. area_id NOT NULL (أو location_note إذا الحي غير محدد)
  3. الخدمة محددة (service_id عبر pivot)
  4. ≥ 1 صورة "بعد" منشورة
  5. عنوان المشروع وصفي

❌ تُحجب (الحالة الراهنة لـ 47 مشروع):
  - owner_confirmed_at = NULL
  - بدون أي صورة

⚠️ إجراء فوري:
  المشاريع الـ47 الحالية = تُضاف meta noindex حتى التأكيد
  OR تُعبَّأ بياناتها مع المالك خلال 30 يومًا
```

## بوابة المقالات (Articles Gate)

```
✅ تمر للنشر:
  1. SEO Metadata كاملة
  2. محتوى > 500 كلمة
  3. رابط داخلي واحد على الأقل لصفحة خدمة
  4. مؤلف مُعيَّن (author field في DB)

⚠️ تحذيرات:
  - بدون مؤلف (يُضعف E-E-A-T)
  - بدون صور (مقبول لكن مُقيَّد Discover-wise)

❌ تُحجب:
  - مقال بمحتوى مسروق أو AI بدون مراجعة
  - مقال بادعاءات بدون دليل (أرقام مختلقة، عملاء وهميون)
```

---

## بوابة العروض (Offers Gate)

```
✅ تمر للنشر:
  1. تاريخ انتهاء العرض محدد (أو «حتى إشعار آخر»)
  2. الخدمة المشمولة مرتبطة
  3. لا أسعار محددة (قبل قرار public_prices)

❌ تُحجب:
  - عروض منتهية لا تُعلَّم (يجب تحديث الحالة)
  - عروض بأسعار غير حقيقية أو تجريبية
```

---

## بوابة الصور (Media Gate)

```
✅ مسموح:
  - الصورة من D:\VibeCleanPro_Media.zip باسمها الأصلي
  - alt text وصفي بالعربية
  - الصورة مرتبطة بمشروع مؤكد (إذا كانت صورة مشروع)

❌ ممنوع قطعيًا:
  - Shutterstock / Getty / AI-generated / صور من مواقع أخرى
  - نسب صورة لمشروع لم تُلتقط فيه
  - «قبل» من موقع مع «بعد» من موقع آخر
  - وجوه بشرية بدون إذن
```

---

## ما يُحكم على كل صفحة قبل النشر

```
1. Is the content TRUE? لا ادعاءات غير مثبتة
2. Is the media OURS? من D:\VibeCleanPro_Media.zip فقط
3. Is the location VERIFIED? أي حي/منطقة ذُكرت — هل مؤكدة؟
4. Is the intent SERVED? هل الصفحة تُجيب على سؤال البحث؟
5. Is the canonical CORRECT? لا duplicate URLs
6. Is the metadata UNIQUE? title/description لا تتكرر
```

## قواعد الطوارئ

```
إذا اكتُشف أن صفحة منشورة تنتهك أيًا مما يلي:
  - صور بدون إذن
  - ادعاء موقع مزيف
  - مشروع بدون تأكيد مالك

الإجراء:
  1. إضافة noindex فورًا (meta tag)
  2. إخطار المالك
  3. حل المشكلة
  4. إزالة noindex بعد الحل
  5. تسجيل الحادثة في هذا الملف
```
