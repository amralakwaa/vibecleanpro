## Scoring Model

Each area scored on 4 axes (0–3 each):
- **SERP Gap** (0=saturated, 3=no competition)
- **Intent Clarity** (0=vague, 3=clear commercial intent)
- **Content Scope** (0=too narrow, 3=rich multi-angle)
- **Evidence Ready** (0=nothing, 1=content blocks only, 2=1+ project, 3=3+ projects with photos)

**Status definitions:**
- `READY` — Can publish now (evidence ≥ 2, score ≥ 9)
- `NEAR-READY` — Publish after adding 1 project (score ≥ 8)
- `NEEDS EVIDENCE` — Excellent opportunity but no documented work yet
- `NEEDS RESEARCH` — Gap unclear, requires more data
- `BLOCKED` — Missing prerequisite (area not in DB, or only 1–2 services with no differentiation)
